PACKAGE CATALOG

软件包目录

发布到 npm 的扩展、技能、提示词模板与主题，用 pi install npm:<package> 一条命令安装。这里是精选示例（描述为中文摘要）；完整的实时目录（数千个软件包）请访问 pi.dev/packages。

浏览完整目录（5000+）→
pi-mcp-adapter
EXTENSION761.4K/月nicopreme

MCP（Model Context Protocol）适配器扩展，让 Pi 可以调用 MCP 服务器上的工具。

$ pi install npm:pi-mcp-adapter
pi-web-access
EXTENSION

为 Pi 提供网页搜索、URL 抓取、GitHub 仓库克隆、PDF 提取、YouTube 视频理解与本地视频分析等网络能力，支持多家搜索服务。

$ pi install npm:pi-web-access
@henryqw/pi-footer
EXTENSION3 个月前发布

在 Pi 的状态栏页脚显示简洁的仓库、分支与用量信息。

$ pi install npm:@henryqw/pi-footer
@henryqw/pi-pr
EXTENSION3 个月前发布

提供 /pr 命令：识别或关联当前拉取请求，然后创建、更新、回应审阅意见、修复 CI，或在你确认后合并。

$ pi install npm:@henryqw/pi-pr
pi-token-budget
EXTENSION3 个月前发布

无摘要的上下文窗口滚动方案：持久化笔记检查点、历史恢复，以及回退后的工具调用围栏。

$ pi install npm:pi-token-budget
@tianhai/pi-workflow-kit
EXTENSION3 个月前发布

在 AI 编码智能体中执行"设计 → 执行 → 收尾"的结构化工作流，并强制 TDD 纪律。

$ pi install npm:@tianhai/pi-workflow-kit
gentle-pi
EXTENSION3 个月前发布

把 Pi 变成"el Gentleman"：带 SDD/OpenSpec、子智能体、严格 TDD 证据、评审护栏与技能发现的高级架构师开发外壳。

$ pi install npm:gentle-pi
@akagilnc/pi-workflow-roles
EXTENSION3 个月前发布

为 Pi 提供绑定式工作流角色。

$ pi install npm:@akagilnc/pi-workflow-roles
@heihei0299/pi-switch
EXTENSION3 个月前发布

轻量的 models.json 配置切换器，在多套模型配置之间一键切换。

$ pi install npm:@heihei0299/pi-switch

没有匹配的软件包。

# 在终端中使用 Pi

在你想要工作的文件夹中运行 `pi`。Pi 会利用该文件夹来发现文件、指令和配置，并对保存的会话进行分组。如果你尚未安装 Pi 或选择模型，请遵循 [快速入门](/docs/quickstart/)。

在加载项目资源之前，Pi 可能会询问你是否信任当前工作文件夹。请参阅 [项目信任](security.md#understand-project-trust)。

记录会显示你的提示词、Pi 的响应、工具调用、结果和错误。你在编辑器中编写提示词和命令。底部栏显示当前文件夹、会话、模型、上下文使用情况以及累计使用量和费用。

## 输入提示词

输入请求并按 `Enter` 发送。使用 `Shift+Enter` 换行，或按 `Ctrl+G` 在配置的外部编辑器中处理更长的提示词。

要包含文件或图片：

- 输入 `@` 搜索文件并将其添加到提示词中。
- 按 `Tab` 补全路径。
- 将图片粘贴或拖入兼容的终端。

## 关注 Pi 的工作过程

Pi 在工作时会显示每次工具调用及其结果。按 `Ctrl+O` 可展开或折叠工具输出。按 `Ctrl+T` 可显示或隐藏思考块。

启动头部列出了 Pi 加载的指令和资源。编辑器边框指示当前思考级别。页脚随模型使用上下文并报告使用情况而更新。

Pi 在每次工具调用前不会询问。请审查命令和变更的文件，并对不受信任或无人值守的工作使用沙箱。参见[安全](/docs/security/)。

## 改变方向

在Pi工作时，你可以发送更多输入：

| 你想要什么 | 操作 |
|---|---|
| 调整当前任务 | 输入消息并按 `Enter` |
| 在当前任务后添加工作 | 输入消息并按 `Alt+Enter` |
| 将排队的消息返回编辑器 | 按 `Alt+Up` |
| 停止当前任务 | 按 `Escape` |

使用 `Enter` 发送的消息会等待当前响应及其工具调用完成，然后引导下一个响应。使用 `Alt+Enter` 发送的追问会等待Pi完成当前任务。中止操作会将排队的消息返回编辑器。

Windows终端保留一些Alt快捷键。请参阅 [终端设置](/docs/terminal-setup/) 获取Windows替代方案。

## 更改模型或设置

输入 `/` 可搜索可用命令。您最常使用的命令包括：

- `/model` 选择模型。按 `Ctrl+L` 可打开相同的选择器。
- `/thinking` 选择当前模型使用的推理程度。按 `Shift+Tab` 可在支持的级别间循环切换。
- `/login` 和 `/logout` 管理提供商访问权限。
- `/settings` 更改常用偏好设置。

提示词模板、技能和扩展可以向同一菜单添加更多命令。请参阅[选择模型](/docs/models/)、[配置](/docs/configuration/)或完整的[斜杠命令参考](/docs/slash-commands/)。

## 继续或重新开始

Pi 会自动保存会话，除非禁用了会话持久化功能。

- `/new` 开始新会话。
- `/resume` 打开另一个已保存的会话。
- `/name` 为当前会话赋予一个可识别的名称。
- `/session` 显示其文件、ID、消息数量、令牌使用量和成本。

当你想在不丢失现有工作的情况下探索其他方法时，可使用 `/tree`、`/fork` 或 `/clone`。使用 `/compact` 可减少发送给模型的对话历史。有关这些工作流程，请参阅 [会话与上下文](/docs/sessions/)。

离开 Pi 后，在同一文件夹中运行 `pi --continue` 可恢复其最近的会话。

## 运行终端命令

在命令前加上 `!` 即可运行它，并将输出包含在对话中：

```text
!git status
```

当你希望运行命令但不将其输出发送给模型时，请使用 `!!`。

## 复制、导出或分享结果

按下 `Ctrl+X` 或运行 `/copy` 复制最后一条助手响应。使用 `/export` 将会话保存为 HTML 或 JSONL 格式。

使用 `/share` 上传会话并获取查看链接。启用 Radius 认证后，工件对您的 Radius 组织可见。否则，Pi 通过 GitHub CLI 创建一个私有 GitHub gist。请先审阅会话，因为其中可能包含对话中暴露的提示词、工具输出、文件内容和凭据。

## 调整终端

在常规模式下，系统使用终端的常规回滚功能。全屏模式则保持编辑器和状态区域固定，而对话记录在终端窗口内滚动。您可通过 `/settings` 或 `--tui-mode` 选择模式。

终端对鼠标输入、键盘快捷键及内嵌图像的支持各有不同。请参阅 [终端配置](/docs/terminal-setup/) 了解平台特定设置，并参考 [按键绑定](/docs/keybindings/) 获取所有可配置快捷键。使用 `/hotkeys` 可查看当前会话中已启用的快捷键。

## 收集诊断信息

在排查终端渲染或会话状态问题时，运行 `/debug`。Pi 会将渲染的终端行和当前会话消息写入你 [代理目录](configuration.md#agent-directory) 中的 `pi-debug.log` 文件。

在分享此文件前请先审阅。它可能包含提示词、模型响应、工具输出、文件内容及终端数据。

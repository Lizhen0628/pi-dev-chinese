# 斜杠命令

在 Pi 的终端编辑器中输入 `/` 可搜索当前会话中可用的命令。本页列出了当前 Pi 版本中的内置命令。

扩展、提示词模板和技能可添加命令。因此，Pi 中的命令菜单是您会话中加载资源的精确参考。

## 模型与设置

| 命令 | 描述 |
|---|---|
| `/settings` | 打开设置 |
| `/model [提供商/模型]` | 选择模型 |
| `/thinking [级别]` | 设置思考级别 |
| `/scoped-models` | 配置交互式循环使用的模型 |
| `/login [提供商]` | 添加提供商认证 |
| `/logout` | 移除提供商认证 |
| `/llama` | 管理已配置的 llama.cpp 路由器上的模型 |

## 会话与上下文

| 命令 | 描述 |
|---|---|
| `/new` | 开始新会话 |
| `/resume` | 切换到另一个已保存的会话 |
| `/name [名称]` | 设置会话显示名称，省略时显示当前名称 |
| `/session` | 显示当前会话信息与统计 |
| `/tree` | 导航会话树 |
| `/fork` | 从较早的用户消息创建新会话 |
| `/clone` | 在当前位置复制当前会话 |
| `/compact [指令]` | 压缩当前上下文，可选用自定义指令 |
| `/import <路径>` | 导入并继续一个 JSONL 会话 |

## 导出与分享

| 命令 | 描述 |
|---|---|
| `/copy` | 复制最后一条助手消息 |
| `/export [路径]` | 将会话导出为 HTML 或 JSONL 格式 |
| `/share` | 上传会话并返回查看链接 |
| `/bug [描述]` | 为 Pi 开发者准备一份私密错误报告 |

在导出或分享会话前，请先进行审查。会话可能包含提示词、工具参数、命令输出、文件内容以及对话过程中暴露的凭据。

## 运行时与项目

| 命令 | 描述 |
|---|---|
| `/trust` | 保存项目信任决策，供未来的 Pi 进程使用 |
| `/reload` | 重新加载按键绑定、扩展、技能、模板、主题和上下文文件 |
| `/hotkeys` | 显示当前激活的键盘快捷键 |
| `/changelog` | 显示变更日志条目 |
| `/quit` | 退出 Pi |

## 资源添加的命令

- 扩展可以注册带有自身参数和补全行为的命令。
- 每个提示词模板以其模板名称可用。
- 当技能命令启用时，技能以 `/skill:名称` 形式可用。

添加或更改发现的命令资源后，请使用 `/reload`。关于加载和命名规则，请参阅 [扩展](/docs/extensions/)、[提示词模板](/docs/prompt-templates/) 和 [技能](/docs/skills/)。
